## Software Components

This repository contains three main software systems:

### 1. ReaperBot (Discord Bot)
A self-hosted Discord bot built in Python that provides:
- Pet RPG system with stats, combat, PvP, tournaments, casino games
- Politics & War integration with nation/war tracking, revenue calculators, war intelligence
- Support ticket system with category routing
- Automatic message translation via Google Translate
- Astrology system with tarot readings and zodiac profiles
- Entertainment commands (roasts, compliments, games)

### 2. PnWHarvester (Data Collection Service)
A standalone asyncio service that:
- Subscribes to PnW API v3 WebSocket events for real-time data collection
- Stores data locally in SQLite databases (GlobalNationsDB, IRSWarsDB, HoldingsDB, etc.)
- Generates narrative news events for wars, trades, and bank transfers
- Processes turn revenue and manages beige alerts
- Uses GPP (Good Parallel Programming) architecture with unified locking, connection pooling, and write buffering

### 3. Web Interface
A FastAPI-based web application embedded within the Discord bot that provides:
- Browser-based pet system interface (adoption, training, casino games, leaderboards)
- PnW analytics tools (war intelligence dashboards, revenue calculators, raid finders, treaty maps, alliance comparisons, news feeds)
- Discord OAuth2 authentication for personal data access
- Real-time WebSocket updates for casino games
- Responsive design for desktop and mobile

## Data Collection and Privacy

This software collects and processes data as follows:

### Discord Bot Data
- Discord User ID, username, discriminator (for user identification)
- Server membership and role information (for command permissions)
- Command usage data (for functionality and debugging)
- Pet system data (stats, inventory, game progress - stored locally)
- Support ticket data (stored locally)

### PnWHarvester Data
- Public Politics & War game data (nation stats, war records, alliance information)
- This data is publicly available via the PnW API and is stored locally for analytics
- No private user data is collected beyond what is publicly available in the game

### Web Interface Data
- Discord OAuth2 authentication data (user ID, access tokens - stored server-side)
- Pet system data (same as Discord bot, shared database)
- User alerts (beige alerts, price alerts - stored locally)
- Session data (stored server-side, expires on logout)

### External API Data
- Translation requests sent to Google Translate (text content only)
- AI prompts sent to Gemini/Groq (no personal data beyond what user provides)
- Image searches via Giphy/Pixabay (search terms only)

All data is stored locally on the user's machine in SQLite databases. No data is transmitted to third parties except through the explicitly listed external API integrations.
